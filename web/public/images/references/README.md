# Fotografías de la referencia

home.jpg y catalog.jpg son las dos referencias visuales entregadas por el usuario.
ReferencePhoto muestra únicamente sus zonas fotográficas con un encuadre CSS, sin incorporar textos ni controles de las capturas al contenido de la web.

Esta solución conserva las fotografías de la propuesta, pero su resolución está limitada por las capturas originales. Para producción, sustituir estos encuadres por las fotografías originales de cada producto y proyecto.

La portada de Home conserva la fotografía que ya existía en images/hero/hero01.jpeg.
