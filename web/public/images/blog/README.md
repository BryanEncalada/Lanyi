# Imágenes del blog

Tamaño recomendado: 800 × 300 píxeles, formato JPG.

- `piso-ideal.jpg`: ambiente con piso de madera.
- `tipos-de-pisos.jpg`: muestras de laminados, madera y bambú.
- `zocalos.jpg`: detalle de un zócalo instalado.

Mientras falten, se muestra la imagen del hero como respaldo.
Los artículos y sus fechas son datos de muestra de la referencia visual.
